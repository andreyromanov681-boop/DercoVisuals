# Gemini project guide

Before working in this repository, read [AGENTS.md](AGENTS.md) and [ATTRIBUTION.md](ATTRIBUTION.md). AGENTS.md contains the project architecture overview, build commands, code-editing conventions, and licensing/attribution guardrails.
