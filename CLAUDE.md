# Claude Code project guide

Read and follow the repository-wide instructions in [AGENTS.md](AGENTS.md) before inspecting or modifying code. Also read [ATTRIBUTION.md](ATTRIBUTION.md) before copying, redistributing, or relicensing inherited code or assets.

Project build: JDK 21, Minecraft 1.21.11, Fabric. On Windows run `./gradlew.bat build`; on Linux/macOS run `./gradlew build`.

Do not infer an open-source license from the repository being public. Preserve existing behavior and attribution unless the maintainer explicitly authorizes a change and the relevant rights permit it.
