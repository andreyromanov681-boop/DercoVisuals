# DercoVisuals shared theme API

The shared theme package is generated by `tools/prepare_pulse_foundation.py` into
`src/main/java/ai/derco/theme/`. Edit the generator, not its generated output.
The API is renderer-independent and has no external dependencies.

## Tokens and accent settings

All colors are opaque ARGB values unless a token explicitly represents an overlay.

```java
import ai.derco.theme.DercoTheme;
import ai.derco.theme.ThemeColors;
import ai.derco.theme.ThemeSettings;

int panel = DercoTheme.color(ThemeColors.Token.SURFACE);
int title = DercoTheme.color(ThemeColors.Token.TEXT_PRIMARY);
int accent = DercoTheme.color(ThemeColors.Token.ACCENT);

// Theme preferences are independent of module state and module logic.
DercoTheme.apply(DercoTheme.settings().withAccentColor(0xFF347BFA));
DercoTheme.apply(DercoTheme.settings().withSecondaryColor(0xFF39D9F2));

// Or replace all theme preferences in one operation.
DercoTheme.apply(new ThemeSettings(0xFF347BFA, 0xFF39D9F2, false, 1.0f));
```

Available token groups include accent/hover/pressed/soft, secondary/soft,
deep background and surface levels, borders/focus, primary/secondary/muted/disabled
text, and semantic success/warning/error colors. The default accent is electric blue;
the secondary accent is cyan.

## Shape, spacing and effects

```java
float cardRadius = DercoTheme.radius(ThemeMetrics.Corner.LARGE);
int cardGap = ThemeMetrics.spacing(3); // 12 px
ThemeEffects.Shadow shadow =
    DercoTheme.shadow(ThemeEffects.Elevation.CARD);
ThemeEffects.Shadow focusedShadow =
    DercoTheme.shadow(ThemeEffects.Elevation.ACCENT_GLOW);
```

The shadow API returns a lightweight descriptor (blur, offset, ARGB shadow and glow).
The caller's renderer decides how to draw it; the theme system does not allocate blur
textures, create threads, or change rendering state.

## Gradients and transitions

```java
ThemeGradients.Gradient header = ThemeGradients.accent();
int midpoint = header.colorAt(0.5f);

// Keep one animation state per widget and update it with the frame delta.
ThemeAnimation.AnimatedFloat hover = new ThemeAnimation.AnimatedFloat(0.0f);
float hoverAmount = hover.update(isHovered ? 1.0f : 0.0f, deltaSeconds, 0.16f);
```

Gradients expose two ARGB endpoints and an axis; they do not issue draw calls.
Animation is frame-driven and allocation-free after the `AnimatedFloat` is created.
`reducedMotion` or an animation scale of zero snaps transitions to their target.

## Contrast checks

```java
int background = DercoTheme.color(ThemeColors.Token.SURFACE);
int text = DercoTheme.readableText(
    background,
    DercoTheme.color(ThemeColors.Token.TEXT_SECONDARY)
);
double contrast = ThemeContrast.ratio(text, background);
boolean accessible = ThemeContrast.meetsWcagAA(text, background);
boolean defaultPaletteIsValid = ThemeContrast.defaultPalettePasses();
```

The contrast helper composites alpha before calculating WCAG relative luminance.
Normal text uses the 4.5:1 AA threshold; large text uses 3:1.
The built-in primary, secondary, muted and disabled text tokens are checked
against all four standard dark surfaces. With the default palette, the lowest
of those built-in text/surface ratios is approximately 4.71:1.

## Integration boundary

ClickGUI, HUD, module cards and future screens should consume this package.
They remain responsible for layout, input, module state and drawing. The theme
package owns only shared presentation tokens, sizing, effect descriptors,
color math, animation math and contrast utilities.
